About This Project

This is a collection of free, open-source developer tools built and maintained by jko-yohan. Every tool is designed with a simple philosophy:

  • Privacy first — All processing happens in your browser. No data is ever sent to external servers.
  • No signup — Use any tool instantly without creating an account or providing an email.
  • Fast and lightweight — Pure HTML, CSS, and JavaScript with no heavy frameworks. Pages load in under a second.
  • Open source — All source code is available on GitHub under permissive licenses.

Whether you are a frontend developer, backend engineer, technical writer, or student, these tools are built to save you time on repetitive tasks. Bookmark this page and come back whenever you need a quick utility.
